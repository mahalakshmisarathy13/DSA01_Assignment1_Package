# Execution evidence guide

The execution logs in this folder were generated in the available build environment where compilation succeeded. Before submitting, compile and run again on your own VS Code setup and capture your own terminal screenshots, because your compiler version and environment may differ.

For each task screenshot:
1. Show the source file name in VS Code.
2. Show the compile command in the terminal.
3. Show the program execution command.
4. Show the complete output without cropping important lines.
5. Save as `TaskXX_output.png` in the matching task folder.

For Task 4 and Task 5, write the predicted output in your report before running the program. The predicted outputs are already included in the task notes.
